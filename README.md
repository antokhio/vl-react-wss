# VL REACT WEBSCOKET EXAMPLE

Shows how to VL React Websocket

### Installation

```sh
git clone git@github.com:antokhio/vl-react-wss.git
cd "vl-react-wss\frontened"

# If no yarn installed, `npm install --global yarn`
# You also need a nodejs installed
yarn

# setup .env according to your enviroment
copy .env-exampe .env

# Development:
yarn dev

# Local server:
yarn host
```

After that is set you should be able to communicate with wss.vl patch
